# date_time

[← Поля и группы полей](../custom-fields.md)

Значение — unix timestamp, то есть конкретный момент времени. В интерфейсе он
показывается по [таймзоне аккаунта](../../configuration.md), поэтому строки без
указания зоны трактуются как местное время аккаунта, а не сервера, на котором
работает php.

```php
$lead->cf('Встреча')->setDateTime('2024-06-01 15:30:00'); // 15:30 по времени аккаунта
$lead->cf('Встреча')->setDateTime(new \DateTimeImmutable('2024-06-01 12:30', new \DateTimeZone('UTC')));
$lead->cf('Встреча')->setDateTime(1717245000);            // сырой timestamp, как есть
$lead->cf('Встреча')->setDateTime(null);                  // очистить значение
$lead->save();
```

Чтение тоже в таймзоне аккаунта:

```php
echo $lead->cf('Встреча')->format();            // Y-m-d H:i:s по умолчанию
echo $lead->cf('Встреча')->format('d.m.Y H:i');
$dt = $lead->cf('Встреча')->getDateTime();      // \DateTime в таймзоне аккаунта
```

`strtotime()` на стороне приложения использовать не нужно: он считает по
таймзоне php-процесса, из-за чего время уезжает, если она отличается от
таймзоны аккаунта.
